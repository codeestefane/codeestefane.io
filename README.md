## 🎯 O que o projeto faz

Este é um portfólio web responsivo que:

- **Apresenta um perfil profissional** com informações pessoais e áreas de interesse
- **Exibe projetos principais** com descrições, links e tecnologias utilizadas
- **Documenta experiências profissionais** e de liderança
- **Cria visualizações interativas** com gráficos dinâmicos usando Chart.js
- **Facilita contato** através de links para email, LinkedIn e GitHub

O site é totalmente responsivo e foi desenvolvido com foco em design limpo e navegação intuitiva.

## 🚀 Como começar

### Pré-requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Nenhuma instalação adicional necessária

### Instalação e Execução

1. **Clone o repositório**
   ```bash
   git clone https://github.com/codeestefane/portfolio.git
   cd portfolio
   ```

2. **Abra o arquivo principal**
   - Opção 1: Abra `index.html` diretamente no navegador
   - Opção 2: Use um servidor local
     ```bash
     # Com Python 3
     python -m http.server 8000
     
     # Com Python 2
     python -m SimpleHTTPServer 8000
     
     # Com Node.js (http-server)
     npx http-server
     ```

3. **Acesse no navegador**
   ```
   http://localhost:8000
   ```

## 💡 Como usar

### Visualizar o Portfólio
1. Abra `index.html` em um navegador web
2. Use o menu de navegação para acessar diferentes seções
3. Clique nos botões dos projetos para acessar os repositórios

### Personalizar o Portfólio
Para adaptar este portfólio para seu próprio uso:

1. **Edite o `index.html`**:
   - Altere nome, foto e descrição pessoal
   - Atualize os links de contato
   - Modifique os projetos e experiências

2. **Customize os estilos**:
   - Edite os arquivos CSS em `assets/style/`
   - Altere cores, fontes e layouts conforme necessário

3. **Atualize as imagens**:
   - Substitua `assets/img/foto_pessoal.jpeg` por sua foto
   - Adicione logotipos de empresas/organizações

4. **Modifique os gráficos**:
   - Edite `assets/js/main.js` para atualizar dados dos gráficos
